# Lens Search

スマホのカメラで撮った写真に似た画像を、登録済みライブラリから探す Google レンズ風 Web アプリ。

- 画像の特徴量は **CLIP (ViT-B/32)** をブラウザ内（transformers.js / WebAssembly）で計算
- 画像も特徴量も端末の IndexedDB に保存。サーバーへ画像は送信されない
- 撮影後に画像をドラッグすると、その範囲だけで検索（レンズの範囲選択に相当）

## 使い方

1. サーバーを起動
   ```bash
   ruby serve.rb 8000
   ```
2. PC なら http://localhost:8000 、スマホなら同じ Wi-Fi で `http://<MacのIP>:8000` を開く
3. 「ライブラリ」タブで検索対象の画像をまとめて登録（初回はモデル約 90MB をダウンロード）
4. 「検索」タブで撮影 → 類似度の高い順に表示

## サンプル画像（samples/ フォルダ）

`samples/` に画像（jpg / png / webp / gif / avif / bmp）を置くと、アプリを開いたときに自動でライブラリへ登録されます。

- フォルダから消した画像は、次に開いたときライブラリからも消えます
- サンプル画像は画面からは削除できません（フォルダで管理）
- 解析結果は端末ごとに保存されるため、各端末で初回だけ解析が走ります

## カメラについて

- `http://<IP>` では **ライブプレビューは使えません**（ブラウザが HTTPS を要求するため）。
  代わりに「📷 撮影・選択」ボタンでスマホ標準カメラが起動し、撮った写真で検索できます。
- ライブプレビューを使いたい場合は HTTPS で配信してください（例: `cloudflared tunnel --url http://localhost:8000`）。
